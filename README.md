# PDF 批量清理工具

批量删除 PDF 里的**图片**和**水印**，支持逐项预览后精确勾选删除。Windows 桌面工具，纯本地运行，不联网。

![图标](icon/icon_a_clean.png)

## 功能

| 能力 | 说明 |
|---|---|
| 一键清理 | 按内置水印词表自动识别并删除；可只删水印或只删图片 |
| 逐项勾选 | 先扫描出每张图、每段文字，看清再勾选，只删勾中的 |
| 图片缩略图 | 勾选窗口直接显示图片，能看清才决定删不删 |
| 重复图片联动 | 内容相同的图片自动归组，勾一张即全选（219 页同一个 logo 一次搞定）|
| 水印块识别 | 逐字绘制的水印（每字一条指令）也能聚合成整句识别 |
| 扫描缓存 | 同一文件二次打开秒开（扫描结果按 文件路径+大小+修改时间 缓存）|
| 多文件并行 | 4 线程同时扫描；命令行版可拖拽文件直接处理 |
| 加密 PDF | 自动识别并跳过，不崩溃 |

## 使用

### 图形界面

1. 解压，双击 `pdf_cleaner_gui.exe`（或 `启动器.bat`，它会在启动失败时自动重试）
2. 「添加文件」或「添加文件夹」→ 选输出目录
3. 两种模式二选一：
   - **一键清理**：按词表自动识别水印，直接开始
   - **手动选择**：点「选择要删除的内容…」→ 在「图片」页签看缩略图、「文字」页签看文本块 → 勾选 → 确定
4. 「开始处理」，完成后可点「打开输出目录」

> 输出目录留空时，结果写到源目录下的 `_cleaned` 文件夹；已存在的同名文件会弹窗确认（可覆盖 / 跳过 / 取消）。

### 命令行

```bash
# 批量处理整个文件夹（删图片 + 删水印）
pdf_cleaner.exe "D:\资料" -o "D:\输出"

# 只删水印，保留图片
pdf_cleaner.exe "D:\资料" --keep-images

# 追加自定义水印词
pdf_cleaner.exe "D:\资料" --patterns "机密,内部资料,禁止外传"
```

完整参数：

```
usage: pdf_cleaner.exe [-h] [-o OUTPUT] [--patterns PATTERNS] [--keep-images]
                       [--keep-watermarks] [--keep-stamps]
                       [--max-run-len MAX_RUN_LEN]
```

- `-o/--output`：输出目录，留空则放到源目录的 `_cleaned` 下
- `--patterns`：追加水印词（逗号分隔）
- `--keep-images`：保留所有图片，只删水印
- `--keep-watermarks`：保留水印，只删图片
- `--keep-stamps`：保留印章批注
- `--max-run-len`：水印文本最大长度，默认 60（超长视为正文，不删）

## 常见问题

**启动时提示 `Failed to load Python DLL`**
安全软件实时扫描会短暂锁定刚写出的 DLL。解决：把程序所在文件夹加入安全软件的信任区，或改用目录版（不产生临时文件）。程序内部也会自动重试等待锁释放。

**提示"输出文件已存在，将被覆盖"**
输出目录里已有上次的结果。选「跳过这些文件」保留旧的，或改选输出目录。

**扫描很慢**
大文件首次扫描需要解析所有内容流（几百页约 8 秒），之后同一文件走缓存会秒开。

## 已知限制

- 逐字绘制的水印可识别；图片型水印（整页扫描件里的字）需要手动选图删除
- 加密 PDF 会跳过，需要先解密
- 文字水印按样式（字号/颜色/角度）+ 位置聚合成块，极端排版下可能误判为正文（长度超 60 字不删）

## 从源码运行

```bash
pip install pikepdf pillow
python pdf_cleaner_gui.py          # 图形界面
python pdf_cleaner.py 文件夹 -o 输出 # 命令行
```

```bash
pip install pyinstaller
python build_gui.py --onefile --distpath . --workpath build_gui
```
